# Livrables visuels

## Principes d’export

- Conserver un master haute définition ou vectoriel.
- Fournir un PNG transparent pour les éléments détourés.
- Utiliser SVG pour les logos et icônes simples lorsque possible.
- Utiliser WebP ou AVIF pour les grandes images du site, avec PNG de secours si nécessaire.
- Nommer les fichiers en minuscules avec tirets : `fyxbot-logo-principal.svg`.
- Éviter d’intégrer du texte dans une image web lorsqu’il peut rester en HTML.

## Discord

Vérifier les dimensions et limites officielles au moment de la livraison. Préparer au minimum :

- une source carrée haute définition pour avatar ou icône ;
- une version lisible en miniature ;
- une bannière avec zone centrale sûre pour les recadrages ;
- des emojis ou stickers sur fond transparent avec silhouette simple.

## Site FyxBot

- Optimiser le poids sans créer d’artefacts visibles.
- Définir une largeur et une hauteur pour éviter les sauts de mise en page.
- Ajouter un texte alternatif utile pour les images porteuses d’information ; laisser vide pour un élément purement décoratif.
- Vérifier le rendu sur fond sombre, mobile et écran haute densité.

## Contrôle final

- Dimensions et ratio corrects.
- Transparence propre et absence de bord parasite.
- Contraste suffisant et texte lisible.
- Aucun secret ou donnée personnelle dans le fichier ou ses métadonnées.
- Licence ou origine de chaque ressource connue.
