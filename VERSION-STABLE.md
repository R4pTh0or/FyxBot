# FyxBot - version stable

Ce dossier de développement prépare la version de référence FyxBot 1.5.0 publiée sur Railway le 28 août 2026.

- Développer et tester dans `C:\Fyxbot`.
- Publier sur Railway uniquement après validation complète et confirmation explicite.
- Exclure de toute synchronisation `.env`, les données SQLite, les sauvegardes, les dépendances et les fichiers de compilation.
- Ne jamais partager un jeton Discord, une clé de chiffrement ou un secret OAuth.
