# Identité visuelle FyxBot

## Logo « visière F »

- `fyxbot-logo-symbol.svg` : version principale sur fond charbon.
- `fyxbot-logo-symbol-transparent.svg` : version transparente.
- `fyxbot-logo-symbol.png` : export PNG 1024 × 1024 pour Discord.
- `fyxbot-logo-symbol-512.webp` : export WebP 512 × 512 pour le web.
- `fyxbot-logo-concept-v1.png` : exploration générée, conservée comme référence créative.

Le symbole combine un **F arrondi**, la **visière lumineuse** de la mascotte et un **bouclier**. Il doit rester sans texte dans les petits formats.

## Bannière

- `fyxbot-banner-master-v1.png` : master généré sans texte.
- `fyxbot-banner-discord.png` : export Discord 1360 × 480.
- `fyxbot-banner-discord.webp` : version WebP 1360 × 480.

Le côté gauche est volontairement libre afin d’ajouter le nom ou du contenu en HTML/vectoriel sans dégrader la lisibilité.

## Palette

- Charbon : `#0D0908`
- Corail : `#FF5A2A`
- Orange : `#FF8A1F`
- Rouge profond : `#E83220`
- Blanc chaud : `#FFF7F3`

## Règles d’usage

- Conserver une marge libre d’au moins 14 % autour du symbole.
- Tester le logo avec un recadrage circulaire avant un envoi sur Discord.
- Ne pas ajouter d’éclair, de flamme, d’armure ou de teinte bleue/violette.
- Garder la mascotte pour les bannières et les grandes illustrations ; utiliser le symbole seul pour les avatars et favicons.
